# nexnclxck-one-fw

[English](README.md)

Личный pet project: часы на ГРИ и обкатка embedded MCU template.

Построены на STM32F051R8: шесть ИН-12Б, четыре ИНС-1, RTC,
высоковольтный преобразователь, подсветка WS2812, кнопки, buzzer и BME280.
Драйверы работают с регистрами через CMSIS. Flash — 64 КиБ, RAM — 8 КиБ.

| Узел | Начальные параметры |
| --- | --- |
| Цифры и разделители | 7 слотов, полный скан 120 Гц, blanking 500 мкс, яркость 100% |
| Часы | ЧЧ:ММ:СС, 24 часа, ведущий ноль; RTC от LSE |
| Мигание точек | PC13 LOW разрешает слот точек; около 500 мс в каждой фазе |
| DC/DC | 180 В, PWM 24 кГц, ADC/PI 1 кГц |
| Консоль | USART1, 1500000 baud, 8N1 |
| Подсветка | 12 WS2812, rainbow, яркость 32/255, обновление эффекта раз в 33 мс |
| BME280 | Forced mode, интервал измерений 500 мс |

После готовности RTC и HV дисплей показывает счётчики RTC, даже если время
не установлено. Настройки устройств хранятся в RAM; RTC и признак установки
времени находятся в backup domain.

## Структура

| Каталог | Назначение |
| --- | --- |
| `platform/` | Запуск MCU, системное тактирование, IRQ-векторы и хуки libc |
| `bsp/` | GPIO, периферия платы, аппаратные драйверы и обработка отказов |
| `apps/` | Часы, индикация, HV, датчик, подсветка, кнопки, звук и CLI |
| `components/` | Библиотеки и независимые компоненты |
| `ports/ui2c/stm32f0/` | Регистровый backend ui2c для STM32F0 |
| `cmake/` | Toolchain, состав сборки и цели OpenOCD |
| `debug/` | Конфигурация OpenOCD и SVD |

`main()` настраивает системное тактирование, вызывает `bsp_board_init()`, затем
`app_main()`. Главный цикл обслуживает приложения, ui2c и консоль.
Файл IRQ-векторов передаёт события BSP. Каждый аппаратный ресурс имеет одного
владельца. Исходники и конфигурация CMake поддерживаются вручную;
[.ioc](nexnclxck-one-fw.ioc) служит справочником распиновки.

## Сборка

Требуются CMake 3.22+, Ninja и Arm GNU Toolchain (`arm-none-eabi-*`) в PATH.
OpenOCD и ST-Link нужны для целей загрузки и отладки.

```powershell
git submodule update --init --recursive
cmake --preset Release
cmake --build --preset Release
```

ELF: `build/Release/nexnclxck-one-fw.elf`. Preset `Debug` использует `-Og -g3`,
`Release` — `-Os -g0` и LTO при поддержке toolchain. Linker script:
`STM32F051xx_FLASH.ld`. Цели OpenOCD: `flash` (program/verify/reset),
`reset` и `erase` (вся Flash).

## Консоль

```text
wsh --exec
clock set -d 2026-11-14 -t 12:34:56
```

| Задача | Команда |
| --- | --- |
| Состояние RTC и календарь | `clock` |
| Дата и время | `clock set -d 2026-11-14 -t 12:34:56` |
| Снять признак установленного времени (admin) | `clock invalidate` |
| Последний результат / монитор BME280 | `bme280` / `bme280 -w` |
| Состояние / монитор преобразователя | `hv` / `hv -w` |
| Уставка HV, 100..250 В | `hv set -v 180` |
| PWM HV, 20000..50000 Гц | `hv set -f 24000` |
| Запрос работы / отключение HV | `hv on` / `hv off` |
| Состояние buzzer | `buzzer` |
| Частота 100..10000 Гц, громкость 0..100% | `buzzer set -f 2500 -v 20` |
| Ручное включение / отключение buzzer | `buzzer on` / `buzzer off` |
| Состояние индикации | `display` |
| Яркость 0..100%, частота 1..400 Гц, blanking в мкс | `display set -b 100 -r 120 -t 500` |

Параметры `set` можно комбинировать; дата и время задаются вместе, годы —
2000..2099. Числовые опции принимают десятичные числа без знака и суффиксов.
Все аргументы проверяются до применения. Неизвестные и повторные опции
отклоняются. `-h` / `--help` показывает справку без выполнения действия.

`clock` показывает дату и время RTC при успешном чтении, с предупреждением
`not set`, если признак установки времени отсутствует. Журнал использует время
RTC при успешном чтении, иначе — время работы устройства. `clock invalidate`
снимает признак установки; счётчики RTC и индикация продолжают работать.

Одновременно активен один монитор. Он печатает начальный снимок и затем
обновляется раз в секунду; пропущенные интервалы не догоняются. Ctrl+C
останавливает вывод. Отключение устройств выполняют `hv off` и `buzzer off`.

HV watch показывает фильтрованное напряжение/уставку, Duty, PWM, измеренный
темп ADC и ошибки приложения/BSP. У первого снимка темп ADC — `n/a`.
`hv on` подтверждает запрос; фактическое состояние указано в статусе.
`hv off` отменяет также автоматические повторные запуски.

`Age` BME280 — время с момента последнего завершённого результата. Занятость
общей I2C-шины откладывает измерение; возраст кэша при этом растёт.
