# BSP STM32F051x8

BSP владеет периферией платы и работает с регистрами CMSIS. Публичные API
устройств не открывают регистры MCU. Системное тактирование, startup,
IRQ-векторы и libc hooks находятся в `platform/`.

## Инициализация и конфигурация

После `SystemClock_Config()` с работающим SysTick вызывается `bsp_board_init()`:

1. GPIO, тактирование DMA и NVIC.
2. RTC и PC13.
3. USART1.
4. I2C1 и его DMA.
5. TIM16 / buzzer.
6. TIM2 / DMA WS2812.
7. ADC, TIM3 и TIM17 / HV.
8. TIM1 / индикация.

Приложение затем вызывает рабочие `*_init()`. TIM1 ожидает корректный план;
TIM3 ожидает готовность ADC. TIM17 имеет CCR1=0 и MOE=0. На PA7 устанавливается
HIGH до подключения AF: инвертирующий NPN-драйвер при этом держит MOSFET закрытым.

| Файл | Данные |
| --- | --- |
| `bsp/include/bsp_board_config.h` | Требуемые частоты устройств |
| `platform/include/platform_config.h` | HSI, PLL и HCLK |
| `bsp/src/bsp_hw.h` | Расчёты таймеров и приоритеты IRQ |
| `bsp/src/bsp_pins.h` | Электроды индикации и PC13 |
| `apps/app_display/src/display_profile.c` | Верхняя плата, символы и параметры скана |

`timer_calc.h` вычисляет PSC с округлением делителя, ARR с усечением периода
и частоту из PSC/ARR. `_Static_assert` проверяют делимость, разрядность регистров,
размеры DMA-буферов и пределы арифметики. AHB/APB имеют делители 1.
Справочный `.ioc` описывает назначение каналов; рабочую настройку выполняет BSP.

## Периферия

| Узел | Конфигурация |
| --- | --- |
| CPU / AHB / APB | HSI / 2 × 12 = 48 МГц, делители шин 1, Flash 1 wait state |
| Время | SysTick 1 мс, `bsp_time_ms()` с переполнением `uint32_t` |
| USART1 | PA9/PA10 AF1, PCLK, 1500000 8N1, oversampling ×16, TX DMA1 CH4, RX CH5 |
| I2C1 | PB6/PB7 AF1 open-drain, HSI 8 МГц, TIMINGR 0x00201D2B, TX CH2, RX CH3 |
| Buzzer | PA6 AF5, TIM16 PWM1, PSC=47, ARR/CCR1 с preload |
| WS2812 | PD2 open-drain, TIM2 CC3 → DMA1 CH1 → GPIOD BSRR, PSC=0, ARR=19, CCR3=10 |
| HV PWM | PA7 AF5, TIM17 PWM1, инвертированная полярность, PSC=0, ARR=1999 (24 кГц по умолчанию) |
| HV ADC | PA2 / IN2, HSI14 14 МГц, 12 бит, sampling 55.5 cycles, TIM3 PSC=0 / TRGO ≈1 кГц, согласован с PWM |
| RTC | LSE, prescaler 127/255, 24 часа, калибровочный выход PC13 1 Гц |
| Кнопки | PC0..PC3 pull-up, EXTI по обоим фронтам |
| Индикация ГРИ | TIM1 1 МГц, ARR=65535, CC1 IRQ priority 1; относительные фазы паузы и свечения, GPIO BSRR, blanking time для TLP127, без DMA |
| Разделители ИНС-1 | Общий сканируемый слот A2, катоды 3/13 слева и 7/10 справа; разрешение PC13 LOW, фаза на границе кадра, без EXTI13 |
| Аноды | ANODE_0..7: PB11, PB10, PB2, PB1, PB0, PC5, PC4, PA5 |
| Катоды | CATHODE_0..15: PB9, PB8, PB5, PB4, PB3, PC12, PC11, PC10, PC9, PC8, PC7, PC6, PB15, PB14, PB13, PB12 |

Аноды и катоды — push-pull, HIGH speed, начальный LOW. BSRR задаёт начальное
состояние до переключения MODER. Неиспользуемые выводы находятся в analog mode.
SWD PA13/PA14, LSE PC14/PC15 и RTC PC13 имеют свои настройки. У PC13 включён
цифровой вход для чтения уровня RTC_CALIB, подтяжки выключены.

## Прерывания

| Приоритет | Источники |
| --- | --- |
| 0 | DMA1 CH1, WS2812 |
| 1 | TIM1 CC1, сканирование |
| 2 | ADC1 / защита HV, разовый TIM17 Update |
| 3 | UART, I2C, их DMA, кнопки EXTI0..3, SysTick |

На refill половины DMA WS2812 отведено 30 мкс. Выборка ADC запускается аппаратно;
задержка её обработчика не сдвигает окно измерения. TIM1 завершает анодный
импульс до расчёта очередного PI. Короткие PRIMASK-участки защищают публикацию
планов, GPIO и общее состояние. Приоритет не устраняет задержку в этих участках.
UART и его DMA используют один приоритет и не прерывают друг друга.

## Консоль

`bsp_console_write()` вызывается одним foreground-производителем с включёнными
IRQ и SysTick. Вызов из ISR или с PRIMASK=1 отклоняется. TX/RX ring — по 64 байта,
RX DMA — 16 байт. `_write()` преобразует LF в CRLF, сохраняя уже заданный CRLF.

Длинная запись заполняет TX ring порциями и возвращается после USART TC,
то есть передачи последнего stop bit. Таймаут 100 мс ограничивает отсутствие
прогресса. При DMA TE переданный префикс завершается через TC; оставшаяся часть
повторяется из foreground. При таймауте передача останавливается, очередь
сбрасывается, возвращается -1. Переданный префикс отозвать невозможно;
повтор сообщения может дать дубликаты. Успех не подтверждает получение терминалом.

Circular RX обслуживается по HT/TC/IDLE. Ошибка UART/DMA останавливает RX;
`bsp_console_process()` перезапускает его, в том числе во время блокирующей записи.
При перезапуске данные теряются. Переполненный ring отбрасывает целый блок.
Обслуживание IRQ должно укладываться в оборот 16 байт — около 107 мкс на 1,5 Мбит/с.

## WS2812

`bsp_ws2812_show()` копирует до 12 RGB-значений и запускает неблокирующую передачу
GRB, старшим битом вперёд. Буфер DMA: две половины по 72 слова GPIO BSRR.
Завершение и ошибки обслуживает DMA IRQ. Фаза CNDTR проверяется до и после refill.

DMA TE, одновременно ожидающие HT/TC, неверная фаза или таймаут 5 мс прекращают
передачу. PD2 переводится в LOW; latch длится 2 мс. `bsp_ws2812_is_busy()`
учитывает передачу, latch и обработку таймаута. Счётчик неудачных передач
`bsp_ws2812_error_count()` позволяет `app_light` повторить кадр после сбоя.

## I2C и buzzer

BSP готовит I2C1, GPIO, clocks, DMA и NVIC. `ui2c_stm32f0` владеет передачами
и аппаратными флагами; `ui2c` — очередью состояния, завершениями и таймаутами.
Таймаут — 100 мс, порог DMA — 16 байт. Неудачная инициализация повторяется
раз в 1000 мс. Арбитраж и BUSY обрабатываются с учётом других владельцев шины;
GPIO recovery не выполняется.

Buzzer использует TIM16, диапазон 100..10000 Гц. Рабочие начальные параметры:
2800 Гц, громкость 10%, выход выключен. Громкость 0..100% соответствует duty
0..50% и не является калиброванной акустической величиной. ARR/CCR1 загружаются
согласованно на границе периода. `app_sound` восстанавливает настройки после
ограниченного по времени сигнала; ручное включение CLI имеет приоритет.

## HV

### Измерение и PWM

TIM17 работает на 24 кГц: 48 МГц / 2000. TIM3 и TIM17 используют одну HCLK
без предделителей. На 24 кГц один триггер ADC приходится на 24 периода PWM:
ровно 1 кГц. Для другой частоты выбирается ближайшее целое число периодов;
отклонение от номинального темпа 1 кГц — примерно до 2,5% в рабочем диапазоне.

Начало выборки смещено примерно на 2 мкс от начала PWM плюс постоянная задержка
запуска таймера/ADC. Sampling — 55,5 тактов HSI14, около 3,96 мкс. Сопротивление
делителя по Тевенину — около 9,9 кОм; допустимый источник для этого sampling —
до 50 кОм по datasheet. При рабочем duty окно находится внутри включённой фазы ключа.
ADC измеряет HV до общего R13; масштаб: VDDA=3,3 В, делитель 101, 12 бит.

TIM17 не имеет внутреннего TRGO-маршрута в TIM3. BSP согласует их счётчики при
старте, смене частоты и сбросе PWM. Новый ARR загружается на границе периода;
разовый IRQ TIM17 затем согласует TIM3. UG TIM3 при согласовании не генерируется,
чтобы исключить лишний отсчёт. Постоянного IRQ на частоте PWM нет.

`bsp_hv_set_frequency()` принимает 20000..50000 Гц из foreground. UDIS и короткая
блокировка IRQ обеспечивают согласованную запись preload ARR/CCR1. Duty, запрос
работы, уставка и интегратор при смене частоты сохраняются. Частота округляется
до реализуемого периода и возвращается к 24 кГц после reset.

### Регулятор

Каждый допустимый отсчёт обновляет IIR с коэффициентом 1/2 и позиционный PI:
`u = Kp * error + integral`. Постоянная времени фильтра на 1 кГц — около 1,44 мс.
Уставка применяется полностью; ограничения скорости изменения duty нет.

- Kp = 80 промилле/В.
- Ki = 1250 промилле/(В·с).
- Ошибка — в милливольтах, интегратор — Q16 промилле.
- Интегратор ограничен 0..duty limit; ошибка не накапливается в сторону насыщения.
- При смене уставки интегратор сохраняется, при off/fault обнуляется.

`bsp_hv_set_duty_q16()` принимает Q16-долю полного периода: 65536 = 100%.
BSP округляет её до такта PWM; шаг на 24 кГц — 0,05 процентного пункта.
В IRQ используется 32-битная арифметика; предельные произведения проверяются
compile-time выражениями в 64 битах. Статус Duty округлён до 0,1%.

### Состояния и защита

Начальная уставка — 180 В, допустимо 100..250 В. После init запрос работы включён;
запуск требует свежего допустимого ADC. RUNNING устанавливается после 50 мс
в полосе ±3 В. Выход из полосы возвращает STARTING, сохраняя управление.
Таймаут восстановления — номинально 20 с; недобор более 10 В даёт NO_REGULATION.
Duty limit — 98%, OVP — 260 В, таймаут свежести ADC — 10 мс.

Первый высокий отсчёт или AWD сбрасывает MOE, сохраняя CCR1 и интегратор.
Три последовательных высоких EOC подтверждают OVERVOLTAGE; между первым
и третьим на 1 кГц проходит 2 мс. Чистый безопасный EOC снимает временную паузу.
AWD без EOC не считается дополнительным высоким отсчётом; возобновление
требует чистого EOC. Во время паузы контроль свежести ADC продолжает работать.
Недопустимые отсчёты обновляют raw-статус, но не фильтр и PI.

`hv off` выключает PWM и отменяет автоповторы. `hv on` принимает запрос,
проверяет готовность и повторяет неудачные попытки с интервалом 1000 мс.
NO_REGULATION, OVP и timeout допускают повторный запуск; INIT и аварийный
shutdown автоматически не перезапускаются. Активный AWD, высокий или устаревший
отсчёт запрещают включение. Повторный `on` работающего HV не сбрасывает PI.

ADC калибруется при ADEN=0, затем включаются analog watchdog, IRQ и внешний
триггер. Готовность ограничена 100 мс; начальный контроль CFGR2 проверяет CKMODE,
игнорируя зарезервированные биты. OVR использует последний отсчёт с overwrite.
`bsp_hv_process()` контролирует свежесть из foreground. Программная защита
требует работоспособных CPU, тактирования и IRQ; duty limit не ограничивает ток.

## RTC и индикация

RTC использует LSE, prescaler 127/255, 24-часовой формат и PC13 / RTC_CALIB 1 Гц.
Обычный reset сохраняет backup domain. Смена источника RTC сбрасывает его.
Дата/время записываются за один INIT-сеанс; magic CLK1 публикуется в BKP0R после
синхронизации. Невалидный календарь гасит дисплей. Учтены обходы ES0202 для
повторного INIT и согласованного чтения SSR/TR/DR. API RTC работает из foreground
с включённым SysTick; в IRQ индикации читается только GPIO PC13.

TIM1 фиксирует фазу PC13 при старте и на границе полного кадра. LOW разрешает
слоты разделителей; HIGH оставляет их тёмными с полной длительностью. Общий
скан содержит 7 слотов, полный период 8330 мкс при 120 Гц / blanking 500 мкс.
Номинальный импульс на 100% — 690 мкс. Публикация плана происходит после гашения
анодов на границе кадра. Профиль, проверка ролей и API: [app_display](../apps/app_display/README.md).

Error_Handler, HardFault и NMI синхронно выключают HV и индикацию перед остановкой.
Shutdown допускает вызов до инициализации и не требует tick. Индикация после
аварийного shutdown остаётся запрещённой до reset.
